# Prototipos de Interfaz (Mockups) 🎨

Esta carpeta almacena los wireframes y diseños visuales iniciales que sirvieron como referencia para el desarrollo del frontend de TechZone Gaming con Astro y Tailwind CSS.

## 🖼️ Vistas Incluidas
* **`Inicio_1.png` / `Inicio_2.png` / `Inicio_3.png`**: Exploración visual de la Landing Page, la barra de navegación, las secciones destacadas y el vitrinismo del catálogo.
* **`PanelAdmin.png`**: Prototipo funcional del dashboard exclusivo para administradores, planteando la tabla de gestión de inventario (CRUD) y el visualizador de estadísticas de la tienda.
